### 🧠 Strategic Focus & Architecture

I bridge the gap between **high-level Agentic AI orchestration** and **low-level systems optimization**:

- 🤖 **Agentic AI & Multi-Agent Systems:** Architecting cyclic, stateful agent graphs with **LangGraph**, **ReAct** iterative loops, deterministic tool calling, structured JSON output validation, and human-in-the-loop controls.
- 🧪 **AI Evaluation & Agent Harnesses:** Passionate about building and tinkering with custom benchmark testbeds and evaluation harnesses (stress-testing tool-calling accuracy, agentic trajectory sandboxes, multi-turn regression suites, and `lm-eval` frameworks) to rigorously probe where models excel and break.
- ⚡ **LLM Inference & Systems:** Accelerating production serving via **vLLM**, PagedAttention, continuous batching, KV-cache optimization, and custom **CUDA** kernel development.
- 🧬 **Model Alignment & Reasoning:** Fine-tuning reasoning LLMs using **GRPO** (Group Relative Policy Optimization) for transparent step-by-step thinking traces and **LoRA / QLoRA** parameter-efficient adaptation.
- 🚀 **Distributed Training at Scale:** Scaling deep learning workloads across multi-GPU setups using **PyTorch FSDP** (Fully Sharded Data Parallel), mixed precision, and gradient checkpointing.
- 🔍 **Production RAG & Vector Systems:** Engineering hybrid sparse/dense retrieval pipelines with semantic reranking, context compression, and vector stores (**ChromaDB**, **FAISS**).
